     3 ОПИС ВИКОНАНОЇ РОБОТИ
     WaterQualityMonitor - це комплексна смарт-платформа для безперервного автоматизованого моніторингу якості води та контролю стану водних ресурсів.
     Система забезпечує безперервний збір фізико-хімічних показників (pH, температура, провідність, розчинений кисень) із сенсорів у режимі реального часу, їх централізований аналіз та автоматизоване керування виконавчими механізмами (актуаторами, такими як аераційні установки). Керування платформою здійснюється через єдиний клієнт-серверний інтерфейс, що включає веб-адміністрування та кросплатформний мобільний додаток, з метою оперативного виявлення екологічних загроз та мінімізації наслідків забруднень.
     Було використано такий технологічний стек:
- Фронтенд-частина: Використано бібліотеку React для створення веб-клієнта. Інтерфейс слугує адміністративною панеллю для управління станціями, налаштування критичних порогів та перегляду історичних графіків.
- Бекенд та База даних: Серверна логіка побудована на платформі Node.js (TypeScript) з використанням фреймворку Express.js. Оскільки система генерує велику кількість структурованої телеметрії, обрано надійну реляційну СУБД PostgreSQL (з можливістю використання SQLite або Firebase для локальних задач).
- Мобільний додаток: Застосовано кросплатформений фреймворк React Native. Це дозволило створити єдину кодову базу для мобільного клієнта під iOS та Android, який забезпечує оперативний контроль та отримання Push-сповіщень.
- Інфраструктура та IoT: Для збору даних у реальному часі використовуються автономні станції на базі мікроконтролерів ESP32 та емулятора на Python.
     На даний момент успішно реалізовано ключове ядро системи. Вдалося побудувати повноцінний клієнт-серверний REST API, який покриває всі потреби взаємодії між модулями. Впроваджено складну бізнес-логіку: сервер приймає дані з датчиків та автоматично розраховує Інтегральний показник якості води (ІКВ).
     Особливу увагу приділено екологічній безпеці: реалізовано систему попереджень, яка миттєво інформує про критичні показники. Більше того, система має логіку автоматичного реагування - вона здатна самостійно надсилати команди на керування актуаторами для стабілізації стану води. Усе це доступно як з браузера, так і через повноцінний кросплатформний мобільний додаток.
     Проект такого масштабу має простір для розвитку, і деякі плани наразі залишилися в статусі концептів для майбутніх ітерацій. Під час проектування було враховано фізичні обмеження: хімічні датчики швидко деградують і потребують обслуговування, а активне використання актуаторів знижує енергоавтономність IoT-модулів. Функцію автоматичного скидання хімічних реагентів було навмисно виключено через високі екологічні ризики.
     У майбутньому планується розширення аналітичних можливостей за рахунок інтеграції модулів штучного інтелекту (ШІ) для предиктивного аналізу. Алгоритми аналізуватимуть динаміку змін показників і прогнозуватимуть критичні ситуації до їх настання (наприклад, падіння рівня кисню), а також виявлятимуть аномалії, відрізняючи природні сезонні коливання від промислових викидів.
     Назва інструменту та версія: Gemini 3.1 Pro.
     Мета використання: Проведення додаткового технічного аналізу архітектурних підходів, структурування ідей щодо інтеграції ШІ для предиктивної аналітики та виявлення прихованих апаратних обмежень IoT-систем у водному середовищі.
     Промпт: «Проаналізуй архітектуру IoT-платформи для моніторингу якості води на базі Node.js, React та React Native. Запропонуй оптимальні шляхи інтеграції ШІ для предиктивного аналізу та опиши неочевидні фізичні обмеження використання датчиків у водному середовищі для формування плану подальшого розвитку продукту.» 
     Внесок автора: Самостійна розробка та практична реалізація програмного забезпечення. Критична оцінка результатів аналізу від ШІ та інтеграція валідних ідей у план майбутнього розвитку (стратегія масштабування). Написання, структурування та оформлення тексту звіту згідно з методичними вимогами університету.
     
     
     
     
     


4 ВИСНОВКИ
     Проєкт WaterQualityMonitor на цьому етапі підтвердив свою технічну реалізованість і практичну значущість. Було створено надійну та масштабовану основу, яка поєднує веб-технології, мобільні рішення, бази даних і концепції Інтернету речей. Запропонована архітектура забезпечує можливість безболісного розширення функціоналу та додавання нових типів сенсорів без порушення роботи існуючих компонентів системи. Платформа переходить від класичного моніторингу до більш сучасного підходу, що дозволяє не лише відстежувати стан водних ресурсів, а й активно впливати на їхню якість через автоматизоване керування.
